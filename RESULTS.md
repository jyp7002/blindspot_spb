## 1. The 2×2, pooled over both arms (design.md §5.1)

inherited = occupation→gender (carried by every base model);
acquired = female→negative valence (injected into T).

| | same-family | cross-family | exogenous | **random null** |
|---|---|---|---|---|
| **Inherited** | **0.400** | 0.555 | 0.643 | 0.298 |
| **Acquired** | 0.462 | 0.471 | 0.410 | 0.227 |

**Primary interaction** (`origin × designer_family`, mixed-effects, random
intercept by (arm, seed), `+ C(arm)`):

**+0.150, 95% CI [+0.015, +0.286], p = 0.030**, n = 45 units.

Per arm:

| arm | interaction | 95% CI | p |
|---|---|---|---|
| qwen | **+0.253** | [+0.018, +0.488] | 0.035 |
| llama | +0.043 | [−0.092, +0.178] | 0.53 |

The interaction is real pooled, but **the Qwen arm carries it**; on the Llama
arm it is indistinguishable from zero.

## 2. The random-partition null — the control that decides interpretability

Not in design.md; added because the self-designer appeared to debias well early
on, which demanded a "does the designer's signal matter at all?" test.

| gap vs null | estimate | 95% CI |
|---|---|---|
| pooled: cross − null | **+0.254** | [+0.179, +0.338] |
| pooled: exogenous − null | +0.274 | [+0.192, +0.349] |
| pooled: same − null | +0.167 | [+0.075, +0.286] |
| **inherited: same − null** | **+0.102** | **[−0.073, +0.220]** |
| inherited: cross − null | +0.256 | [+0.112, +0.352] |
| acquired: same − null | +0.236 | [+0.069, +0.470] |
| acquired: cross − null | +0.244 | [+0.100, +0.481] |

This is the cleanest statement of the blind spot in the whole study:

> **On inherited bias, a same-family designer's signal is statistically
> indistinguishable from a random partition of the same sentence pool
> (+0.102, CI covers 0). On acquired bias the same designer is clearly above
> the null (+0.236). Cross-family designers are above the null on both.**

Note the null is *not* near zero (0.298 on inherited): negating almost any
contrast built from gendered minimal pairs lands in the gender subspace. Any
study of this kind without such a null will overstate its designers.

## 3. Bidirectional control (design.md §5.1) — **passes**

The question: is this a same/cross *relation*, or just "Llama-3B is a more
responsive designer"?

**Relation view** — (cross − same) must be positive in every arm:

| arm | cross − same | 95% CI |
|---|---|---|
| qwen | +0.270 | [+0.082, +0.447] |
| llama | +0.039 | [−0.161, +0.209] |

**Lineage view** — each lineage's apparent quality must flip when the arm flips:

| designer lineage | as cross-family | as same-family | flip |
|---|---|---|---|
| Llama-3B | 0.615 | 0.502 | **+0.113** |
| Qwen-3B | 0.410 | 0.298 | **+0.113** |

Both lineages debias the *other* family's target better than their own, by an
almost identical margin. This is the control passing: the asymmetry is not
reducible to designer strength. (Pre-edit, each designer's elicitation gap is
*constant* across arms — Qwen-3B −0.056, Llama-3B +0.146, Gemma-2B +0.090 —
so the flip cannot come from the elicitation gap alone.)

Caveat: positive in both arms but the Llama arm's CI covers 0, so the
CI-strict version of the criterion fails.

## 4. Direction alignment — the mechanism in weight space

cosine(designer's contrast direction, exogenous ground-truth direction), from
20 000-d sketches (72 sketches, 12 references):

| | same-family | cross-family | random null |
|---|---|---|---|
| **Inherited** | +0.029 | **+0.144** | −0.059 |
| **Acquired** | **+0.081** | −0.051 | −0.027 |

Same-family designers recover the right direction on *acquired* bias and barely
better than null on *inherited* bias; cross-family is the reverse. Alignment
predicts removal: **r = +0.381, p = 0.0013** (Spearman ρ = +0.462, p = 7e−5,
n = 68).

## 5. Binarization is essentially free (H1) — **passes**

At matched collateral (each variant at its own best α inside the budget,
n = 50 conditions):

- binary retains **99%** of full-precision task-vector negation
  (median ratio 0.990, IQR [0.890, 1.059])
- mean MMLU cost of the binary edit at its frontier point: **−0.0034**

design.md §7 asked for ≥70% retention and ≤1–2 pt MMLU drop. Comfortably met:
**sign + per-tensor scale loses almost nothing relative to full precision.**

## 5b. Ablations (design.md §5.5 / §5.6) — Qwen arm, seed 0

| variant | dBias | bytes |
|---|---|---|
| binary per-tensor, 50% sparse | **0.472** | 4.8 MB |
| full precision | 0.443 | (fp16 dense) |
| binary per-tensor, 90% sparse | 0.437 | **963 KB** |
| binary per-tensor, dense | 0.422 | 9.6 MB |
| binary per-channel, dense | 0.421 | 9.6 MB |
| binary **scalar** scale, dense | 0.345 | 9.6 MB |
| binary per-tensor, 99% sparse | 0.261 | **96 KB** |
| **binary per-tensor, RANDOM SIGNS** | **−0.004 ± 0.004** | 9.6 MB |

Three results here matter:

1. **The random-sign control is flat zero** (−0.004). Same scale, same
   sparsity, signs shuffled ⇒ *no debiasing whatsoever*. The sign **structure**
   carries the entire signal. This is design.md §5.5's control and it passes
   emphatically — and it sharpens §2: a random *partition of the data* still
   works (0.298) because any gendered-minimal-pair contrast lands in the gender
   subspace, but a random *sign pattern* does nothing at all.
2. **Bit budget**: 90% sparsity (963 KB, 7.7M flips) matches the dense binary
   and full-precision edits. 99% sparsity (96 KB) still retains 62%. So the
   "few KB" framing of §7 is not reachable at full strength, but ~1 MB is, and
   that is three orders of magnitude below the model.
3. **Binary integrity**: per-channel scale buys nothing over per-tensor
   (0.421 vs 0.422); collapsing to a single global scalar costs ~18%
   (0.345). The binary story does not need continuous scale leaking back in.

| criterion | verdict | value |
|---|---|---|
| SIGNAL_ABOVE_NULL | **PASS** | +0.254, CI [+0.179, +0.338] |
| BIDIRECTIONAL_CONSISTENT | **PASS** | +0.039 (llama), +0.270 (qwen); lineages flip |
| H2 acquired ratio (>0.8) | **PASS** | 0.982 |
| H1 binary retention (≥0.7) | **PASS** | 0.990 |
| H1 MMLU cost (≤0.02) | **PASS** | −0.0034 |
| KILL/PIVOT | **not triggered** | cross−same = +0.149, CI [−0.012, +0.318] |
| H2 interaction significant (p<0.01) | FAIL | p = 0.030 |
| H2 inherited ratio (<0.3) | FAIL | 0.721 |
| H2 axis coverage (≥3 of 4) | FAIL | 2 axes (MVP scope) |
| H2 primary success | **FAIL** | composite |
| H3 mechanism | **FAIL** (two-arm) | see below |

**H3 flipped sign of verdict when the second arm landed.** On the Qwen arm
alone it passed cleanly (endogenous deficit +0.270 CI [+0.082, +0.447];
exogenous ≈ cross, −0.011 CI [−0.066, +0.115]). Pooled over both arms the
endogenous deficit is +0.166 with CI [−0.012, +0.361] (covers 0) and the
exogenous signal is now *better* than cross-family (+0.163, CI [+0.054, +0.319])
rather than equal to it. So the strict H3 statement — "the interaction vanishes
under ground truth" — is **not** supported once the Llama arm is included; what
survives is the weaker ordering exogenous ≥ cross > same on inherited bias.
This is exactly why design.md §5.1 mandates the second arm.

## 8. A premise of design.md §3 that does not hold

design.md rests H2 on "disjoint pretraining lineage ⇒ different bias profile".
Measured across 8 models, occupation→gender skew is **+0.65 to +0.86 in every
lineage** (Qwen, Llama, Gemma, Phi, SmolLM2) — see
`results/axis_verification.json`. The cross-family designer is *just as biased*,
so it cannot be succeeding because it doesn't share the bias. Across the whole
22-axis inventory the most family-differentiated axis (religion) has a
between/within-family SD ratio of only ≈3 (`results/family_divergence.json`).

The bidirectional flip (§3) shows the effect is nonetheless *relational*. So the
mechanism is not "the cross designer lacks the bias" but something closer to
"a designer cannot get leverage on a bias it expresses in the same weight
directions as its target" — which is the transmission-geometry story of
design.md §10, not the disjoint-bias story of §3.

## 9. Methodological findings

1. **Elicitation method is decisive, and two natural choices are invalid.**
   Free generation: models "debias" by dropping the pronoun entirely
   (Llama-3.2-3B produced *zero* scoreable items), and the corpora then differ
   in pronoun *presence*, not gender. Forced-choice A/B judging: sub-4B models
   sit at chance even on the biased side, and judging supplied text measures
   *recognition*, which survives where exhibition does not. Likelihood-based
   self-debiasing (Schick-style, read off the model's own preferences) is what
   works. Chosen on pilot, as design.md §12 requires.
2. **Recognition ≠ exhibition** — models often recognise stereotypes they still
   exhibit, so the blind spot is behavioural, not a failure of explicit
   recognition.
3. **‖v‖ is the wrong summary of a designer's signal.** A designer choosing
   near-randomly yields a *large* undirected contrast; a consistent one yields a
   small well-aimed contrast. Hence the alignment sketches (§4).
4. **Bias injection needs regularisation from a disjoint split.** Unregularised
   injection took perplexity 15.0 → 34.6 (a damaged model, not a biased one);
   regularising from the *same* WikiText split then trained on the eval texts
   (perplexity fell to 12.0 — contamination). Final recipe: regulariser from
   `train`, eval on `test` → skew +0.552, ppl 13.2, MMLU 0.635 vs 0.645 base.

### Bugs caught that would each have silently corrupted results
- Phi-3.5's SentencePiece tokenizer maps `" he"`/`" she"` to the same first
  token → its occupation-gender skew read exactly 0.000. Fixed with
  tokenizer-agnostic continuation scoring (real value: 0.730).
- An injection template hard-coded "He", producing *"a female colleague … He
  seemed careless"* and corrupting the *other* axis (occ_skew 0.688 → 0.347).
- The resume key omitted the arm, so every Llama condition collided with a
  completed Qwen key and the entire bidirectional run wrote **nothing**.
- Editing a running bash script shifted its byte offsets mid-execution and
  corrupted the command it had not yet read.
