# v5 closure — the self-repair blind spot is a small-model phenomenon; at 7–9B self-repair *ties*

**Companion to `design.md`, `experiments_v2–v5.md`, `SUMMARY_V4.md`. Consumes the
full v5 artifacts: the seed-completed abstract gate (V1), the seed-filled T2
panel (t2x), and the 6-family bridge tier (x + x2).** Every number here is
computed by `src/v5_analyze.py` from the measured `removal.jsonl` files — no
hardcoded baseline constants (R2-bug rule). All CIs are percentile bootstrap
(10k resamples, seed 0) resampling the **target×axis cells** — the unit the
pre-registration names for the gate.

---

## One-paragraph result

The abstract gate is decided: with the pre-registered three seeds, size-matched
same-family-large designers debias 7–9B targets **no worse** than cross-family
designers (paired Δ = **+0.016**, 95% CI **[−0.026, +0.055]**, covers 0) →
**V1-a → Abstract A**. The v4 self-*advantage* does **not** survive the seed
fill: at 7–9B a model's self-repair is **statistically tied** with every other
designer class — same-family-large (V1-c: self − same_large = −0.016,
CI [−0.073, +0.044]) and cross-family (t2x: cross − self covers 0 on both axes).
So the honest 7–9B claim is *"no penalty — a tie,"* not *"own best debiaser."*
The bridge tier (2.5–3.8B) is **not a clean size-monotone crossover**: family and
axis dominate size, and **Phi-3.5-mini (3.8B) shows the strongest, cleanest
occupation-gender penalty in the whole program (+0.288, CI [+0.219, +0.362],
zero budget-fails)** — a persistent penalty at ~4B — while gemma-2b already
self-advantages at 2.6B. Durable geometry, non-durable and family-contingent
behavioral tax.

crows {gemma −0.104, llama +0.005, olmo −0.045, qwen +0.017}.

> **Methodological note (recorded so it cannot recur).** An interim analysis
> reported a *significant* crows self-advantage (CI [−0.064, −0.002]). That CI
> pooled per-(target, seed) points (n = 12), treating seeds within a target as
> independent replicates — anti-conservative. Resampling the **target cell**
> (n = 4), the correct unit and the one the gate uses, the CI covers zero. The
> 7B self-advantage is **not** supported; the defensible claim is a tie.

The family-level self-penalty (cross − same{self, sibling}) is likewise a tie:
occ +0.064 [−0.005, +0.132]; crows −0.017 [−0.080, +0.038]. **No penalty, no
advantage, at 7–9B — the blind spot has closed.**

## 7. Limitations (verbatim candidates)

- **7B tie rests on n = 4 families** (t2x) and the gate on **n = 3 families ×
  2 axes** (V1); CIs are wide. The tie is "no detectable penalty," not "proven
  zero."
- **Bridge crossover is family-contingent, cause unidentified** — phi carries a
  clean ~4B occ penalty while gemma does not; size alone does not order the arc.
- **granite is collateral-fragile at both 2.5B and 8B** (self cannot debias occ
  within the ΔMMLU ≥ −0.02 / ppl ≤ 1.10 budget → nan; reported nan→0). A
  size-independent instrument fragility, not a bias result. falcon-occ carries
  1/3 self budget-fails, so its +0.264 is partly a nan→0 floor.
- **Categorical penalty cause still unidentified** (family-level correlation
  only; H1 ρ = −0.81 is ≤3B, n = 8).
- **T4 geometry = 2 large families; 70–72B deliberately unrun.**
- **Base-only durability at 27B — RESOLVED (Y1 PASS).** gemma-2-27b base
  re-profiled; Δd_base = +0.184 [+0.082, +0.280] excludes 0 and exceeds Δd_it
  (+0.136). Residual limitation: the cross-family peer (qwen32b) is instruct —
  the whole registry is, so cross-family bias is instruct on both sides; a fully
  base cross-family 32B was not run.
- **Cross-designer sets differ slightly between x and x2 targets** (x2 targets
  see the full 6-family pool; original-x targets see the 3-family pool) —
  each (cross − self) is still a within-target contrast, but cross-mean
  composition is not identical across targets.
