# docs/history — superseded design and results documents

Per-version records from v2–v10, kept for provenance. **Nothing here is read by
code**, which is the criterion used to decide what could move: the documents
that regen modules read as INPUTS stayed at the repo root, namely
`RESULTS_METHOD.md`, `RESULTS_METHOD_v9.md`, `RESULTS_V8.md`, `V8_FINDINGS.md`,
`V9_CLOSEOUT.md` and `design.md`. Moving those would break `make freeze`.

Current documents live at the root: `PREREGISTRATION.md` (all designs and
amendments, v2 through v11), `experiments_v11.md` (the live design), the draft,
and the generated `V10_*` reports.

Note `experiements_v2..v5.md` keep their original misspelling; renaming them
would break the links in `PREREGISTRATION.md`.
